# Product and Revenue Roadmap

## Phase 1 — Foundation

- Governed Hermes router and clone registry
- CI, tests, security policy, and contribution rules
- Application adapter contracts and audit events

## Phase 2 — First useful applications

- Corporate-services intake assistant
- Opportunity and revenue research clone
- Publishing and interactive-content workflow
- CRM follow-up preparation with human approval
- QA and whistleblower review lane

## Phase 3 — Platform

- Visual workflow builder
- Multi-tenant identity and permissions
- Usage metering, subscriptions, and affiliate attribution
- Connector marketplace with sandboxed adapters
- Operational dashboards and cost controls

Each application should prove one customer problem, one measurable result, and one revenue path before expanding.
